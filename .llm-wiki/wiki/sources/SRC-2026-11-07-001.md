# Meta DAT — Getting Started with the Toolkit

> _Original: [https://wearables.developer.meta.com/docs/develop/dat/getting-started-toolkit/](https://wearables.developer.meta.com/docs/develop/dat/getting-started-toolkit/)_

## Summary

Official entry point for the Meta Wearables Device Access Toolkit. Covers platform
requirements, installing platform-specific AI coding guidance, and preparing glasses
and the Meta AI app for development.

Platform floor is **iOS 17.2+** with Xcode 26.4+, or **Android 10+** with Android Studio
Flamingo or newer. Android projects need **Kotlin 2.2+** because the toolkit is compiled
with Kotlin 2.2. This became a real constraint when scaffolding
[LocalGlasses](/syntheses/localglasses-android-setup.md): it forced a move to AGP 9's
built-in Kotlin, since the Kotlin Gradle Plugin was pinned below 2.2 elsewhere.

The AI-assisted path is two choices — app platform and coding tool — then install the
matching plugin/skills and connect documentation search. Supported plugin clients are
Claude Code, Codex, and Muse Code (experimental). Cursor, Copilot, and other
checked-in-file readers use repo-native installs via `install-skills.sh`. A plain
`AGENTS.md` at the repo root carries the same guidance as the plugin skills, which is
the only option for clients not on the list — relevant to
[Pi](/entities/pi-coding-agent.md).

## Key Takeaways

- Requirements: iOS 17.2+/Xcode 26.4+, or Android 10+/Android Studio Flamingo+ and **Kotlin 2.2+**.
- `install-skills.sh` takes a client argument: `muse`, `claude`, `codex`, `copilot`, `cursor`, `agents`, `all`.
- Installing the Claude Code / Codex / Muse Code plugin also wires up the Wearables MCP server — no separate MCP config.
- An AI agent in an already-running session will not see a freshly installed plugin until restart; read the repo `AGENTS.md` instead.
- Developer Mode in the Meta AI app is what lets unpublished apps register; the app then appears under App connections → Developer mode apps.
- Hardware matrix covers Ray-Ban Meta Gen 1/2, Ray-Ban Meta Optics, Meta glasses, Meta Ray-Ban Display, Oakley Meta HSTN, Oakley Meta Vanguard.
- Glasses firmware version lives in Meta AI → Devices → gear → General → About → Version.
