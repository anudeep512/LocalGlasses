# AGP 9 — Migrate to built-in Kotlin

> _Original: [https://developer.android.com/build/migrate-to-built-in-kotlin](https://developer.android.com/build/migrate-to-built-in-kotlin)_

## Summary

AGP 9.0 makes Kotlin support built into `com.android.application` / `com.android.library`
and enables it by default. Applying `org.jetbrains.kotlin.android` alongside it now fails
with *"Cannot add extension with name 'kotlin'"* or *"plugin is no longer required"*.

The migration is four mechanical removals: drop the `kotlin-android` plugin from module and
root build files (and its version-catalog entry), swap `kotlin-kapt` for
`com.android.legacy-kapt` or KSP, move `android.kotlinOptions {}` to top-level
`kotlin.compilerOptions {}`, and stop adding Kotlin sources via `kotlin.sourceSets {}`.

A subtlety worth keeping: with built-in Kotlin you do **not** set
`kotlin.compilerOptions.jvmTarget`, because it defaults to
`android.compileOptions.targetCompatibility`. Setting it explicitly is harmless but redundant.
Escape hatches exist — `android.builtInKotlin=false` plus `android.newDsl=false` — but the
page states the flag disappears in AGP 10.0, so opting out is temporary by design.

This is the exact migration LocalGlasses needed; see
[LocalGlasses Android setup](/syntheses/localglasses-android-setup.md). Note the Compose
compiler plugin (`org.jetbrains.kotlin.plugin.compose`) is **still required** — built-in
Kotlin replaces only `kotlin-android`.

## Key Takeaways

- AGP 9.0+ enables built-in Kotlin; `org.jetbrains.kotlin.android` must be removed, not version-bumped.
- The Compose compiler Gradle plugin is separate from `kotlin-android` and is still applied.
- `jvmTarget` defaults to `compileOptions.targetCompatibility` — no manual setting needed.
- `kapt` is incompatible; use KSP or `com.android.legacy-kapt` at the same AGP version.
- Kotlin source dirs go through `android.sourceSets { kotlin.directories += ... }`, not `kotlin.sourceSets`.
- Opting out (`android.builtInKotlin=false` + `android.newDsl=false`) stops working in AGP 10.0.
- `android { enableKotlin = false }` disables Kotlin per-module for modules with no Kotlin sources.
